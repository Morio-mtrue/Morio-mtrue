## Hi, I'm Njoroge Ngumi

Pharmacist and data analyst based in Kenya. I build practical tools for public health and digital health: software that makes health data easier to trust and decisions easier to defend.

**I work on:** health commodity procurement, medicine safety data, health information systems, and applied machine learning.

### Featured work

| Project | What it does |
| --- | --- |
| [**health-commodity-tender-agent**](https://github.com/Morio-mtrue/health-commodity-tender-agent) | An AI agent that prepares the evaluation file for a health commodity tender committee, then stops. Every criterion is cited to its source page, prices are checked by code, award history comes from Kenya's public OCDS data, and a named person approves each step. Python, LangGraph, MCP, local open-weights model. |
| [**ppb_recalls**](https://github.com/Morio-mtrue/ppb_recalls) | Scripts that collect medicine recall and rapid alert notices published by Kenya's Pharmacy and Poisons Board into usable CSV and PDF archives. Python, web scraping. |

### Private work

Some of my work runs on real patient and study data, so the code stays private. Happy to walk through it on request.

- **Trachoma surgery audit dashboard.** A privacy-first web dashboard and data pipeline that pulls field audit forms from KoboToolbox, validates each record against the audit protocol, pseudonymises patient identifiers, and shows supervisors what needs correcting. TypeScript, Cloudflare Workers, D1.
- **WASH and trachoma study analysis pipeline.** A reproducible analysis pipeline for a school-based water, sanitation and hygiene study: numbered, re-runnable cleaning modules with full cleaning, query and deviation logs, plus an API backend for the study dashboard. Python, pandas, FastAPI.
